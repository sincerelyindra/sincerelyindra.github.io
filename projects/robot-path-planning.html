Path planning for a wheeled robot from aerial images

Indra Kumar, Aditya Mohan, Siddharth Jain, and Thandava S

Given an aerial image and start and goal coordinates, the project identifies traversable paths, selects a route, and controls a wheeled robot along it. It was developed for CP 214: Foundations of Robotics at IISc.

Team project connecting visual segmentation, path planning, and robot control. Course instructor: Prof. Shishir N. Y. Kolathaya.

View code on GitHub

Approach

  • Used a U-Net model to extract traversable regions from aerial imagery.
  • Compared path-planning variants, including diagonal moves in a modified A* search.
  • Applied separate PID controllers to linear and angular velocity.
  • Integrated the components in a robot-following-path simulation and addressed coordinate scaling, model compatibility, and controller tuning.

Results

The presentation demonstrates the complete workflow from an aerial image to a planned route and simulated robot motion.

Experimental scope

The demonstrated system assumes aerial images captured parallel to the ground. Drone coordination, additional sensors, and Kalman filtering are proposed extensions.
