Strategic bidding in online auctions

Indra Kumar and Thandava Sai

Project repository ↗

We combined interpretable statistical models with reinforcement learning to study bidding styles. The analysis uses features derived from the Shill Bidding Dataset, including bid timing, burstiness, bid share, winning ratios, and bidder experience.

Team project integrating feature engineering, strategy labelling, choice models, behavioural interpretation, and a simulated DQN bidding agent.

View code on GitHub

Approach

  • Created strategy labels through rules and K-means clustering, then fitted multinomial and mixed logit models.
  • Used Gaussian-mixture segmentation to explore bidder groups and examined Bayesian control-function estimation.
  • Interpreted bidding styles through Level-k reasoning.
  • Trained a DQN agent for 5,000 simulated episodes with experience replay and a target network.

Results

The multinomial model achieved 99.5% test accuracy and a weighted F1 score of 0.995 against the project’s generated strategy labels. The DQN learned a hybrid bidding style in the simulated environment.

IISc Open Day study

The project report also describes a Lowest Unique Positive Integer behavioural game conducted at IISc Open Day with 3,842 participants, in groups of 7–10. The aggregated choices were used to discuss levels of strategic reasoning.

Experimental scope

Strategy labels were constructed from behavioural features rather than independent expert annotations. Auction-agent results use a simplified simulation with fixed opponent types.
